# negative

사진을 캔버스에 올려 흑백·반전 필터를 적용하고 합성·저장하는 편집기.

---

## 실행

`실행.bat` 더블클릭

---

## 사용법

1. 캔버스 클릭 또는 사진 드래그 → 사진 추가
2. 사진 클릭 → 선택
   - 드래그 → 이동
   - 파란 코너 핸들 → 크기 조절
   - 주황 핸들 → 회전
3. 캔버스 밖으로 드래그 → 삭제
4. 우클릭 → 레이어 순서 / 삭제
5. 모드 버튼으로 전체 필터 변경 (원본 / 흑백 / 반전 / 흑백+반전)
6. **저장** → `C:\negative\edited\`

---

## 요구사항

- Python 3.10+
- Pillow
